# TAJA.EXE — 레트로 타자연습 기획서

> v0.2 · 2026-10-27

## 1. 컨셉

**"1995년 컴퓨터실에서 켠 한메타자교사"**
파란 DOS 화면, 도트 폰트, 키를 누를 때마다 들리는 8비트 '틱' 소리.
성격은 **제대로 된 연습 도구가 메인, 게임은 보너스**.

## 2. 무드 / 톤 (연출 강도: 적당히, 가독성 우선)

| 항목 | 방향 |
|---|---|
| 배경 | DOS 파랑 `#0000AA`, 흰색/노랑 텍스트, 회색 이중선 박스 |
| 폰트 | 도트 비트맵 폰트 (Galmuri — 한/영 모두 지원) |
| 커서 | 깜빡이는 `█` 블록 커서 |
| 사운드 | 키 입력 "삑", 오타 "부-", 완료 칩튠 팡파레 — Web Audio 합성 |
| 연출 | CRT 스캔라인 / 부팅 화면은 **설정에서 켜는 옵션 (기본 OFF)** |
| 조작 | 키보드만으로 전부 가능 (방향키, Enter, ESC, F-키). 마우스도 지원 |

## 3. 언어

- 한글 + 영어. 메인 메뉴에서 `한/영` 전환 (Tab 키)
- 한글 자판: 두벌식 표준

## 4. 기능 범위

### MVP (1차)

| # | 기능 | 비고 |
|---|---|---|
| 1 | 메인 메뉴 + 한/영 전환 | 키보드 조작 |
| 2 | 자리 연습 | 화면 키보드에 칠 키 하이라이트. 단계별(기본 자리 → 윗줄 → 아랫줄 → 전체) |
| 3 | 낱말 연습 | 낱말 하나씩 |
| 4 | 짧은 글 연습 | 타수·정확도·오타 하이라이트 |
| 5 | 결과 화면 + 기록 보기 | 최고 타수, 평균, 최근 10회 도트 막대 그래프 |
| 6 | 효과음 + 설정 | 사운드 / CRT / 부팅 연출 on/off |

- 기록은 localStorage. 로그인 없음.

### 2차
- 긴 글 연습 (저작권 없는 글)
- 산성비 게임
- 테마 3종 (파랑 DOS / 초록 모노크롬 / 호박색 터미널)

### 보류
- 랭킹, 로그인, 사용자 문장 등록

## 5. 측정 기준

- **타수**: 분당 타수(타/분). 한/영 동일하게 "키 입력 수" 기준
  - 한글: 정확히 입력한 글자를 자모 단위로 분해한 키 수 (`닭` = ㄷㅏㄹㄱ = 4타, 쌍자음은 Shift 포함 1타로 셈)
  - 영어: 정확히 입력한 문자 수 (공백 포함)
- **정확도**: 맞은 글자 / 전체 비교 글자
- **오타 판정**: 한글 조합 중(IME composing)인 마지막 글자는 확정 전까지 오타로 보지 않음
